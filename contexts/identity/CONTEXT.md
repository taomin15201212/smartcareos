# Identity

Identity 统一人员、服务和设备的身份，并判断主体是否可以对某项业务资源执行动作。

## Language

**主体**:
发起访问或操作的人员、服务或设备。
_Avoid_: 账号、用户

**授权范围**:
主体被允许访问的机构、老人、设备和动作集合。
_Avoid_: 权限字符串

**API 凭据**:
服务主体用于证明身份并关联租户授权范围的可轮换秘密。
_Avoid_: 密码、Token 字符串

**租户边界**:
一个租户业务资源可被访问和变更的最外层授权边界。
_Avoid_: 租户参数

**凭据轮换**:
为同一主体签发新 API 凭据并撤销旧凭据的受控过程。
_Avoid_: 修改密码

**审计事件**:
对主体访问、变更及其结果的不可变事实记录。
_Avoid_: 业务日志、调试日志

**监护授权**:
家属主体针对指定老人、用途和数据范围获得的有效授权。
_Avoid_: 家属绑定
