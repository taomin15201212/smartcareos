# M12 性能与容量基线

基线脚本并发请求健康端点，输出平均、P95 和最大响应时间。默认规模为 200 请求、并发 10，可通过 `SMARTCAREOS_PERF_REQUESTS` 和 `SMARTCAREOS_PERF_CONCURRENCY` 调整。

验收门槛：本地单实例零错误，P95 小于 500 ms。该结果用于开发机回归，不等同于生产容量承诺；正式容量需使用脱敏业务数据，在目标网络、MySQL 与消息中间件规格上复测。

## 来源事实与架构推演

- 来源事实：招聘信息提及 MySQL、消息队列和 IoT 接入。
- 架构推演：200 请求、并发 10 与 P95 500 ms 是当前工程门槛。
